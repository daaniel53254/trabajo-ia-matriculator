Como se parsea un JSON

Parsear es convertir un texto con formato JSON en datos que el programa puede usar. Es lo que hace Matriculator cuando el servicio de Python devuelve la matricula y la confianza a la interfaz de JavaScript.

1. Idea general

El JSON viaja siempre como texto. Para usarlo hay que parsearlo en tres pasos:

1. Texto

Llega una cadena de caracteres, sin estructura todavia.

2. Piezas

Se recorre el texto y se separan llaves, claves, valores y signos.

3. Datos

Con las piezas se construye un objeto (diccionario en Python) con tipos reales.

Los datos de entrada sinteticos del apartado 3 de demo_lenguajes.ipynb (imagen, camara, tamano...), en los dos lenguajes del proyecto:

Python (servicio de IA)

import json

texto = '{"imagen": "entrada_01.jpg", "camara": "entrada_norte", "tamano_mb": 2.4}'

# loads = leer desde un texto (string)
datos = json.loads(texto)

print(datos["camara"])      # entrada_norte
print(datos["tamano_mb"])   # 2.4 (numero)

JavaScript (interfaz web)

const texto = '{"imagen": "entrada_01.jpg", "camara": "entrada_norte", "tamano_mb": 2.4}';

// parse = leer desde un texto (string)
const datos = JSON.parse(texto);

console.log(datos.camara);      // entrada_norte
console.log(datos.tamano_mb);   // 2.4 (numero)

En el notebook se usa json.load (sin la s) porque lee desde un fichero. json.loads lee desde un texto, que es lo que llega por la red.

3. Errores tipicos

Si el texto no cumple la sintaxis, el parseo falla y el programa debe controlarlo (en Matriculator, mostrando un error y no una pantalla en blanco).

ErrorIncorrectoCorrecto
Comillas simples{'camara': 'entrada_norte'}{"camara": "entrada_norte"}
Coma final{"a": 1, "b": 2,}{"a": 1, "b": 2}
Clave sin comillas{camara: "entrada_norte"}{"camara": "entrada_norte"}
Falta cerrar{"a": 1{"a": 1}
Valor no valido{"a": undefined}{"a": null}

Python

try:
    datos = json.loads(texto)
except json.JSONDecodeError as error:
    print("JSON no valido:", error)

JavaScript

try {
  const datos = JSON.parse(texto);
} catch (error) {
  console.log("JSON no valido:", error.message);
}
