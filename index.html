Sistema de Reconocimiento de Matrículas

Propuesta Técnica de Inteligencia Artificial

1. Introducción
y Caso de Uso

Matriculator es una aplicación orientada a automatizar el acceso a aparcamientos mediante la detección de matrículas en imágenes de cámaras de seguridad.

Su diseño prioriza la agilidad en el flujo vehicular y el cumplimiento estricto de la privacidad, integrando tecnologías de visión artificial y OCR de última generación.

Flujo del Sistema

  • 1 Usuario sube imagen del vehículo
  • 2 Sistema valida formato y tamaño
  • 3 IA detecta y extrae matrícula
  • 4 Evaluación de confianza
  • 5 Resultado automático o revisión humana

4. Lenguajes de marcado y formatos de datos

Matriculator utiliza diferentes formatos para crear la página, guardar datos y pasar información entre las diferentes partes.

Formato ¿Para qué sirve? Uso en Matriculator
HTML Crear y organizar todo el contenido de una página web. Interfaz que usaría el usuario.
XML Organizar y compartir datos de una forma bien estructurada. Intercambio de información con otros sistemas.
JSON Representar e intercambiar datos con claves y valores. Enviar datos de imágenes y recibir los resultados de la IA.
Markdown Dar formato a textos, listas, tablas y enlaces. Documentación del proyecto con el README.md.
CSV Almacenar datos organizados en filas y columnas. Datos de Google Trends usados para el gráfico.

2. Comparativa de Lenguajes
y Decisiones

📊 Análisis de Interés Global (Google Trends)

Python encabeza de forma absoluta el interés mundial en búsquedas destinadas a Inteligencia Artificial

⚙️ Características Fundamentales

Python

Sobresale por su sintaxis intuitiva y limpia, facilitando desarrollo rápido y mantenible.

  • ✓ Fácil aprendizaje
  • ✓ Ecosistema IA superior
  • ✓ Despliegue web

R

Estándar absoluto para cálculo estadístico avanzado, pero menor versatilidad en producción.

  • ✓ Análisis estadístico
  • ✗ Débil en IA
  • ✗ Despliegue complejo

Otros

JavaScript, C++, Java y PHP quedan rezagados en ecosistema de IA y visión artificial.

  • ✗ Poco soporte IA
  • ✗ Complejidad alta
  • ✗ Menos librerías

📚 Tabla de Bibliotecas para IA y Datos

Lenguaje Bibliotecas Clave Enfoque Principal
Python OpenCV, EasyOCR, TensorFlow, PyTorch, Pandas Visión artificial, Deep Learning y Ciencia de Datos
R caret, randomForest, ggplot2 Estadística y modelado analítico
JavaScript TensorFlow.js IA en navegadores / Interfaces web

⚖️ Matriz de Decisión

Python

Facilidad: Alto | Estadística: Alto | IA: Excelente | Web: Alto

R

Facilidad: Medio | Estadística: Excelente | IA: Medio | Web: Bajo

Otros

Rezagados en IA | Complejidad variable | Soporte limitado

🎯 Decisión Final

Lenguaje elegido: Python para la gestión global y la capa de visión artificial / OCR

¿Son distintos? No. Usamos Python para ambas capas, unificando el código y evitando complejidad.

¿Por qué se descartan los demás?

  • C++: Complejidad excesiva y tiempo de desarrollo prohibitivo
  • R: Falta versatilidad para integrar modelos en web producción
  • Java/PHP: Ecosistema débil en librerías de IA nativas
  • JavaScript: Rezagado en disponibilidad de modelos Deep Learning preentrenados
